Privacy Policy

homelab-rclone · Last updated 2026-11-01

homelab-rclone is a personal backup tool built on rclone. It signs in only to its owner's own Google account. It does not offer accounts to anyone else and does not collect data from other people.

Google data it accesses

With the owner's permission, homelab-rclone uses one Google API scope:

  • drive.file: to upload, list and delete the backup files it created itself. It cannot see any other file in the Drive.

How the data is used and stored

  • The data is used only to store encrypted backups of the owner's home server in the owner's own Drive.
  • Backups are encrypted before upload. The OAuth token is stored on the owner's private server. Nothing is sold, shared or sent to any third party.
  • The app does not use Google user data for advertising, and it does not train any AI model on it.

homelab-rclone's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Remove homelab-rclone at any time at myaccount.google.com/permissions. The stored token then stops working, and the owner deletes it from the server.
